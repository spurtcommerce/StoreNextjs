StoreNext External Templates Folder
-----------------------------------
This directory hosts storefront templates.
The 'default' template is built-in.

To install and run the Horizon template:
1. Copy the compiled 'dist-template/horizon' (or 'templates/horizon') folder into this directory as 'horizon'.
2. Run or restart the standalone server (node server.js).
3. The application will dynamically detect, serve, and execute the template!
